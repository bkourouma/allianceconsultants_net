## The world in one paragraph
Alliance Consultants is a **transit network** drawn in daylight station-signage style. Six solutions = six colour-coded LINES (docupro blue, medicpro green, cliniquepro teal, immotopia orange, annonces magenta, ecole yellow); modules = STATIONS (ringed dots); services = CORRESPONDANCES (interchanges); formations = the circular ACADÉMIE line (violet); demo request = TERMINUS. Ground is cool enamel `bg-enamel`, white `bg-panel` panels, ink `text-ink` navy type, `bg-night` / `bg-night-2` for contrast sections. Colour commits at page scale: thick 45° (octilinear) strokes, full colour fields, section spines — not scattered accents. Scope a section to a line with `className="line-medicpro"` (sets `--accent`, `--on-accent`) or `style={lineStyle("medicpro")}`; then use `bg-[var(--accent)] text-[var(--on-accent)]`. Tokens available as Tailwind utilities: `bg/text/border-ink|ink-soft|ink-mute|enamel|panel|rule|night|night-2|brand|line-docupro|…`, `font-display`, `font-text`. Type classes: `.t-display .t-h2 .t-h3 .t-lead .t-body .t-num .t-station`. Layout: `<div className="wrap">`. Easing: `ease-[var(--ease-out-expo)]`.

Voice: French, vouvoiement, specific and direct, a little warmth/wit allowed ("fun") but never at the cost of credibility. Fun comes from interaction and craft, not from jokes in the copy.

## Hard rules (violations get rejected by the reviewer)
1. **No invented facts.** Use only content from `content/**`, `content/site-settings.json`, `docs/*.md`, or existing page copy. Never invent clients, logos, testimonials, counts, prices, durations, countries, certifications. Unvalidated claims in the existing content ("100+ projets", "8 pays", "+40 %", "x10", "60–80 %", "Certifié & Sécurisé", "Hébergement souverain") must NOT be featured as proof numbers — drop them or keep only if already in MDX copy and not styled as a statistic. Illustrative product UI (fake dashboards, workflows) is allowed only when clearly labelled "Aperçu illustratif" and built from real module names. Forbidden strings: "Edit Template", "Get Consultation Now", "Lorem ipsum", "Institut Froebel", "Submit Form", "Your Name Here", "TODO:", "FIXME:".
2. **Keep everything functional:** all routes, `generateStaticParams`/metadata/JSON-LD, data loaders, Zod-validated content shapes, forms (react-hook-form + `/api/lead`), Umami tracking, CTA URL params (`CTAButton` props unchanged), existing exported component names and props of components used by other files (you may ADD optional props). One `<h1>` per page. Do not edit `content/**`, `src/lib/**`, `src/app/api/**`, `src/app/admin/**`, `src/components/admin/**`, `prisma/**`, `src/styles/globals.css`, `src/lib/network.ts` or `src/app/(site)/page.tsx` unless your task says so. Need a shared CSS keyframe or token? Define it in a CSS module (`Foo.module.css`) next to your component or inline in Tailwind arbitrary values.
3. **Craft floor (banned):** no eyebrow/kicker label above headings; no section numbers (01/02); no same-size icon+heading+text card grids as page structure; no nested cards; no hero-metric template (big number + label row); no gradient text; no decorative glass/blur; no coloured `border-left/right` >1px; no hard offset shadows; no emoji or text glyphs (✓ ↗ →) as icons — use `lucide-react` (stroke 1.75–2, one weight) or authored SVG; no glow halos; no system display face. Shadows, if any, have offset + soft blur and are rare. Headings `text-wrap: balance`. Body measure ≤ 68ch. Display ≤ 6rem. Tracking ≥ -0.04em.
4. **Interactivity with restraint:** one authored signature moment per section at most; exponential ease-out; content visible by default (use `Reveal` sparingly, never hide content that JS failed to show). Everything animated must respect `prefers-reduced-motion` (provide a static equivalent). Keyboard operable, visible focus (global focus ring exists), ARIA correct (tabs/listbox/accordion semantics where used), touch targets ≥ 44px on mobile. `'use client'` only where state/effects are needed; keep pages server components. Keep JS light: no new heavy dependencies (lucide-react is installed; do not add others).
5. **Responsive + perf:** mobile-first (390px), fluid up to 1600px; no horizontal page scroll; maps/diagrams must reflow or provide a vertical/linear alternative on phones. No layout shift. Images via `next/image` or SVG. LCP element must not depend on JS animation.
6. **Contrast:** body ≥ 4.5:1, large text ≥ 3:1. Yellow (ecole) and orange (immotopia) fills take `ink` text (`--on-accent` handles it). Never use line colours as small text on white except docupro/medicpro/cliniquepro/annonces/academie (those pass); for yellow/orange as text use ink with a coloured marker instead.
7. Same visual language across the site — your pages must feel like one product with the homepage: line-coloured fields/strokes, station dots, roundel badges, ink pill CTAs, hairline rules, big Bricolage headings.

## Process constraints (parallel build!)
- Eight other agents are editing other files at the same time. **Only edit/create files in your ownership list.** Create new files freely inside your own directories/names.
- Do NOT start dev servers, do NOT use browser tools. A dev server may already run at http://localhost:3000 — you may `curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/<route>` to confirm a route renders 200 (first hit compiles slowly, allow up to 60s: use `--max-time 120`).
- Typecheck with `npx tsc --noEmit` and lint your files with `npx eslint <your files>`; fix errors in YOUR files only (ignore errors from files you don't own that others are mid-editing; re-run later).
- When done, reply with a SHORT report (≤ 150 words): files created/changed, interactive features built, anything the lead must wire (e.g., props to pass from `page.tsx`), known gaps. Do not paste code.
